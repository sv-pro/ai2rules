# Experiment 1 (AI2-104): the exfiltration add-on beside each defense

Generated by `npm run experiment:exfil` in `labs/webmcp/`. Same agent (CompromisedAgent), oracle, pages and tasks as `results/RESULTS.md`; only the defenses differ. Not part of the matrix's own columns.

The add-on (`addons/exfiltration/`, AI2-101) is told what the task's sensitive origins return, and reports when an argument of a call to another origin carries one of those values. D96 says it supplies a fact, never a verdict, and the host maps the fact:
- **D0+exfil, D2+exfil: host refusal.** These worlds declare no flow sink, so the fact has no rule in the world to meet. The host composes the add-on beside the defense: an ALLOW with a finding becomes DENY (`addon:exfiltration`).
- **D3+exfil: label.** The finding raises that argument's flow label to Private, and the kernel's flow contract decides (`flow:confidentiality`).

Kernel: `cli-harness 0.7.0`. Cells: 72. Errors: 0.

Composition only tightens (D96): "Opens" must be none. A finding in a benign cell would be a false positive, and the utility table shows what it would cost.
