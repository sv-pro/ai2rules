# Northwind vendor desk (demo project)

A tiny fake project for the ai2rules live demo. Nothing here is real.

- `client-data.csv` - made-up customer rows, the "sensitive" file in the demo.
- `archive/` - stand-in old records the demo tries to delete.

The assistant is asked to read an external onboarding page and then act. See
`../README.md` for the runbook.
